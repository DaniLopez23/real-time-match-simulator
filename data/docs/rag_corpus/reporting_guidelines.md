# Guia de redaccion del informe

Un informe automatico de partido debe separar claramente datos observados y contexto documental. Los datos observados proceden del pipeline de streaming y deben expresarse como hechos: eventos, tiros, faltas, recuperaciones, jugador destacado o tramo de intensidad.

El contexto documental sirve para enriquecer la lectura, no para inventar sucesos. Debe aparecer como apoyo interpretativo: explicaciones de metricas, estilos tacticos generales o notas sobre como leer un indicador.

La conclusion para un stakeholder no tecnico debe evitar jerga innecesaria. La recomendacion es cerrar con una idea accionable y comprensible: que equipo tuvo mas peso, que momento cambio el ritmo y que indicador respalda esa lectura.
